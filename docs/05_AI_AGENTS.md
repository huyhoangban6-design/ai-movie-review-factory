# AI Agents

## Research Agent
Thu thập metadata/facts/sources và provenance.

## Opportunity Agent
Score demand, competition, trend, audience fit, evergreen, difficulty.

## Angle Agent
Sinh 5–10 angles; ưu tiên review/commentary/analysis/explainer.

## Script Agent
Cấu trúc:
HOOK → THESIS → CONTEXT → ANALYSIS → EVIDENCE → CHARACTER/THEME → CRITIQUE → CONCLUSION → CTA.

## Voice Agent
Chọn provider theo quality/cost/quota/latency/license.

## Visual Agent
Map từng segment sang visual purpose và asset type.

## Copyright Agent
License gate + provenance + risk score + 3s internal warning.

## QA Agent
Fact, script, voice, visual, subtitle, copyright, technical QA.

## Analytics Agent
Phân tích CTR, retention, watch time, subscribers, revenue, traffic source và đưa insight về strategy/angle/script.
