# PRD — AI Movie Review Factory

## Người dùng
Creator vận hành kênh YouTube review phim bằng điện thoại.

## Job-to-be-done
Chọn phim đáng làm, tìm góc nội dung, nghiên cứu, viết review, tạo voice, lập visual timeline, kiểm tra bản quyền, render, QA, upload private, duyệt và theo dõi analytics.

## MVP
Movie input → research → script → TTS → visual plan → FFmpeg → subtitle → export.

## Các module production
Movie Intelligence, Opportunity Engine, Content Angle Engine, Research/Fact Engine, Script Engine, Voice Manager, Visual Planner, Asset Engine, Copyright Engine, Video Engine, Subtitle Engine, Thumbnail/Metadata, QA Engine, Publishing Engine, Analytics/Learning, Cost Engine.

## Human checkpoints
CP1 Angle
CP2 Script
CP3 Voice
CP4 Visual/Copyright
CP5 Final
CP6 Publish
