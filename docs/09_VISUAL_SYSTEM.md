# Visual System

Visual Planner không chèn clip máy móc. Nó tạo visual plan theo purpose.

Asset types:
- AI-generated image
- licensed stock
- poster/official promotional material khi phù hợp
- permitted/licensed clips
- graphics/text/charts
- transformed visual elements

Mỗi asset lưu:
source, source_url, license, commercial_use, owner,
acquisition_time, usage_context, duration, transformations, risk_score.

Asset thiếu provenance/license metadata không được vào final render.
